# Argon Gate — Site Institucional

Site institucional/landing page da **Argon Gate**, construído com [Next.js](https://nextjs.org) 16 (App Router), React 19, TypeScript e Tailwind CSS v4.

## Começando

Instale as dependências e inicie o servidor de desenvolvimento:

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) no navegador para visualizar o projeto.

## Scripts disponíveis

- `npm run dev` — Servidor de desenvolvimento (Turbopack)
- `npm run build` — Build de produção
- `npm run lint` — Executa o ESLint

## Tecnologias

- [Next.js](https://nextjs.org) 16 (App Router)
- [React](https://react.dev) 19
- [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS](https://tailwindcss.com) v4
- [Lucide React](https://lucide.dev) (ícones)

## Deploy

O projeto possui deploy contínuo na [Netlify](https://www.netlify.com). A cada push na branch principal, o build é disparado automaticamente pela plataforma.
